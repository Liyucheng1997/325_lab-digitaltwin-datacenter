# 数字孪生机房 · Digital Twin Data Center

基于 Three.js 的浏览器端数字孪生机房，无需构建工具，静态 HTTP 服务即可运行。

## 运行

```bash
python -m http.server 5173
```

然后打开 <http://localhost:5173>。也可以用 `npx serve -l 5173 .`。
three.js 通过 jsdelivr CDN 的 import map 加载，需要联网。

## 功能

- **机房建模**：2 排 × 6 个 42U 机柜（计算 / 数据库 / GPU / 存储机柜）、核心网络机柜（路由器、防火墙、双核心交换机、带外管理）、UPS + 电池柜 + 低压配电柜、3 台精密空调 (N+1)、架空网络桥架、架空母线槽、穿孔地板与冷通道封闭。
- **连接关系**：每台服务器的网络路径（核心 → 桥架 → ToR → 网卡）与供电路径（UPS → 母线槽 → 插接箱 → PDU → 双电源）都以线路 + 流动粒子呈现。
- **运行过程**：冷/热气流粒子闭环（穿孔地板 → 冷通道 → 服务器 → 热通道 → 吊顶回风 → 空调），报文/电流粒子按服务器负载实时发射。
- **服务器抽出 + 拆解**：点击服务器可从机柜抽出，进入拆解视图查看机箱顶盖、硬盘、风扇墙、背板、主板、CPU 散热片、内存、GPU、网卡、RAID 卡、冗余电源等部件；点击部件显示其工作原理与实时指标。
- **仿真指标**：每台服务器的负载 / 温度 / 功耗、机柜功耗、IT 负载、PUE、UPS 电池、空调风机等均实时计算。
- **四个演示流程**：一次请求的完整旅程、供电链路、冷却循环、故障告警与冗余切换，逐步讲解并联动相机、高亮与粒子。
- **故障注入**：服务器过热、市电中断、空调停机，观察系统冗余响应。

## 目录

```
index.html          页面骨架
css/style.css       样式
js/config.js        机房布局、机柜模板、角色、部件与设备说明
js/scene.js         渲染器、相机、灯光、飞行
js/room.js          机房 / 机柜 / 网络设备 / 供配电 / 空调 / 桥架 / 路径
js/server.js        服务器外观、内部结构、抽出 / 拆解动画
js/flows.js         报文 / 电流 / 气流粒子
js/simulation.js    负载、温度、功耗、告警、UPS/空调状态
js/interaction.js   鼠标拾取
js/ui.js            面板、KPI、日志
js/process.js       运行过程演示脚本
js/main.js          入口
```

## 操作

- 左键拖动旋转，右键平移，滚轮缩放
- 点击设备查看详情；再次点击已选中的服务器可抽出 / 推回
- `Esc` 取消选择并推回所有服务器
